# 竞品档案（2026-09 公开资料）

## 1. 源氏木语 Yeswood（主对照）

- 官网：https://www.yeswood.com/  电话 400-6123-598  
- 公司口径：2010 上海创立，属万木生源集团；员工近万；自称 2025 中国实木家具销量第一、黑胡桃销量第一。  
- 规模：官网首页写线下门店 1600+；新闻稿曾写国内超百万平方米生产、胶州智能家居园、全球 12 家木场。  
- 集团子品牌：维莎、百伦沙、朵艺、阿纳尼、方迪、西物、加兰、源氏木语 kids、涵客、源也等。  
- 木头：对外主打 100% 纯实木、北美 FAS 黑胡桃、白蜡、白橡、樱桃、红橡、榉木。买家实测：可视面用好料，背板 / 抽屉底 / 床铺板常见桐木等辅材，要逐件看详情。  
- 系列：大众线、黑胡桃线、黑标（挑板、五金、填充，木种不一定换）。  
- 工艺话术：大板直拼、榫卯 + 现代五金、木蜡油 / 净味漆、FSC / SGS。审美偏北欧、中古、奶油、儿童彩木。  
- 价格带（评测/电商常见成交，非实时）：  
  - 入门红橡 / 橡胶木小件、部分床：约 2000 内到 4000  
  - 常规 1.8m 床：约 3800–4300，黑标床 7000+  
  - 沙发：约 4288（入门）到 8600–9290（黑标 / 旗舰）  
  - 书柜：约 1900–5000  
- 交期：官方新闻 45–60 天；有延期、分批发货、色差投诉。  
- 服务：全国大量城区送装；2025 口径「十年质保、终身保修」；可量房、部分定制。  
- 图片：`images/yeswood/`（官网素材 + 首页截图）

## 2. 维莎原木

- 店铺：https://weisha.pw666.cn/  
- 与源氏：社区和客服口径多为同一集团、不同定位。有到货箱印源氏、同一发出地的买家帖。  
- 木头：更多橡胶木、橡木入门；同造型电视柜，维莎两千档橡胶木 vs 源氏三千档黑胡桃的对比帖较常见。  
- 价格：整体低于源氏，适合小件、次卧小床。维莎一旦贴到源氏价，没必要选维莎。  
- 对头木：不要打维莎低价。客户若只看「便宜实木」，先问清是不是橡胶木。

## 3. 原始原素

- 青岛原始原素，约 2010，电商北欧实木。淘宝 / 京东旗舰店。  
- 木头：橡木、榉木、北美黑胡桃、樱桃。强调全实木、健康漆。  
- 公开价举例：橡木茶几约 2300+；橡木沙发组合约 4700+；黑胡桃 1.8 床约 1.0–1.4 万；黑胡桃电视柜约 8900；新中式黑胡桃真皮沙发约 1.1 万。整体常比源氏大众线贵一截。  
- 对头木：风格近北欧标准件。黑胡桃标价高，头木若同料定制，要用「可改尺寸 + 交期」讲话，不要只报一个总数。

## 4. 治木工坊 / 木邻 / 失物招领（高一档网红实木）

- 社区常把治木工坊、木邻、失物招领放在源氏之上：白橡 / 黑胡桃 / 樱桃，设计溢价，定制更常见，价格明显高于源氏大众线。  
- 对头木：这批拼审美和内容，不拼镇店量。头木不必学他们的定价话术，学「把木种和结构讲清楚」。

## 5. 林氏木业（对照「不是一类」）

- 大众板式 / 板木为主，款多价低。社区普遍不把它和源氏、原始原素放同一「纯实木」篮子。  
- 对客户只用来解释：板材胶水多、不能当实木比价。

## 6. 头木木业（本店）

- 江西上饶广丰桐畈，陈师傅，浮雕数控出身，2024 回乡自立。  
- 木：北美黑胡桃、樱桃、红橡、白蜡；对照表还有山毛榉、橡木、松木。  
- 在售方向：全屋来图、胡桃床、布艺沙发、新中式储物沙发、茶几、满月梳妆台、无床头床、茶颜边柜。  
- 周期：站点 7–15 天。
